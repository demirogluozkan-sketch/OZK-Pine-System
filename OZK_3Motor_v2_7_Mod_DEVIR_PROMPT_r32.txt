================================================================

Bu kurallar r01-r17 arası yaşanan hataları özetler. Yeni kod yazarken ÖNCE BURAYA BAK.

   ```pine
   method foo(Type t) => [a, b]    // ❌ CE — yasak
   ```

2. **METHOD İÇİNDE VAR DECLARATION YASAK**
   ```pine
   method foo(Type t) =>
       var int x = 0               // ❌ CE — yasak
   ```
   Çözüm: x'i type field yap (FilterEngine.rsi_above_bars)

3. **METHOD İÇİNDE SELF := METHOD() ZİNCİRİ YASAK**
   ```pine

       s := s.lock_motor("AT")     // ❌ CE10175 — yasak
   ```
   Çözüm: s.locked_motor := "AT" (direkt field atama)

4. **FONKSİYON PARAMETRESİ MUTABLE OLAMAZ**
   ```pine
   foo(TradeState s) =>
       s.field := değer            // ❌ CE10175 — yasak
   ```
   Çözüm: method kullan (method'da self mutable)

5. **MULTI-LINE TERNARY — PARANTEZSİZ SORUNLU**
   ```pine
   a = cond ? val1 :              // ❌ satır sonu value+: → CE10156
       cond2 ? val2 : val3
   ```
   Çözüm: Dış parantez ekle veya if/else kullan

6. **NZ() BOOL SERİSİ KABUL ETMEZ**
   ```pine
   not nz(entry_long_ok[1])       // ❌ CE10123 — yasak
   not entry_long_ok[1]           // ✅ OK — direkt [1]
   ```

7. **TEXT_SIZE INT DEĞİL STRING ALIR**
   ```pine
   text_size=12                   // ❌ hatalı
   text_size=size.normal          // ✅ OK
   ```

8. **TYPE FIELD ÜZERİNDE [N] OPERATÖRÜ YASAK (CE10290)**
   ```pine
   at_motor.long_entry_ok[1]      // ❌ CE10290 — yasak
   ```
   Çözüm: Önce yerel değişkene al:
   ```pine
   _ok = at_motor.long_entry_ok   // yerel bool series
   _ok[1]                          // ✅ OK
   ```

9. **MATH.SUM() FLOAT DÖNDÜRÜR — INT FIELD'A CAST GEREKİR (CE10173)**
   ```pine
   x := math.sum(...)              // ❌ CE10173 — float→int yasak
   x := int(math.sum(...))         // ✅ OK — int() cast
   ```

10. **FORWARD REFERENCE YASAK (CE10271)**
   ```pine

   method foo(Motor m) =>
       status_bg(...)              // ❌ CE10271 — status_bg henüz tanımlı değil
   // SECTION 6'da:
   status_bg(...) => ...           // çok geç!
   ```
   Çözüm: Çağrılan fonksiyon her zaman çağırandan ÖNCE gelmeli.
