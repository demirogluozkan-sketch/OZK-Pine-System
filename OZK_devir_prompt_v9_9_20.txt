ANA AMAÇ
- Lean (sade) mimari
- Deterministik davranış
- Non-repainting / no-lookahead disiplini
- Bar close bazlı event-driven mantık
- Strategy ve indicator parity
- Chop bölgelerinde gereksiz işlem azaltma
- Audit ve dashboard ile görünürlük
- Daha çok işlem değil, daha kaliteli işlem

- Lean mimari bozulmasın

- Repaint / lookahead olmasın
- Raw / gated / final ayrımı bozulmasın
- Audit görünürlüğü kaybolmasın
- Dashboard gereksiz kalabalıklaşmasın

- Önce öner, sonra onay al, sonra uygula

ANA MİMARİ

REJİM
- regime_long_ok  = close > (use_atr_buffer ? regime_upper : regime_ema)
- regime_short_ok = close < (use_atr_buffer ? regime_lower : regime_ema)

MOTOR SEÇENEKLERİ (7 adet)
- AT    : AlphaTrend tek başına
- GC    : G-Channel tek başına
- ST    : SuperTrend tek başına
- EMA   : EMA200 tek başına
- AT-EMA: Fiyat>AT>EMA stack (giriş), EMA hold
- GC-EMA: Fiyat>GC>EMA stack (giriş), EMA hold
- ST-EMA: Fiyat>ST>EMA stack (giriş), EMA hold — v9.9.20'de eklendi

EXIT ÖNCELİK SIRASI
1. Backtest bitiş kapaması
2. ST Raw Flip Exit
3. Regime Break Exit
NOT: ATR Trail Exit bu projede aktif değil

RAW / GATED / FINAL AYRIMI
- raw    = sadece ham engine event (confirmed bar + flip)
- gated  = raw + regime gate + filter gate
- final  = gated + reentry lock + cooldown + state kontrolü

CANLI KULLANIM MODELİ
- Indicator = canlı alarm / webhook / Osmanlı emir akışı
- Strategy  = backtest / parity analizi
- TradingView'de 4 ayrı alarm: OZK LONG AC / LONG KAPAT / SHORT AC / SHORT KAPAT
- Osmanlı JSON mesajı TradingView alarm penceresindeki Mesaj alanına yapıştırılır

ST-EMA MOTOR KURALLARI (v9.9.20 ile eklendi)
- Long giriş : ST flip + Fiyat > ST > EMA200 stack
- Short giriş: ST flip + Fiyat < ST < EMA200 stack
- Long hold  : close > EMA200 (sadece EMA bazlı)
- Short hold : close < EMA200 (sadece EMA bazlı)
- Çıkış      : STEMA STOP (fiyat EMA'nın yanlış tarafına geçince)
